## Prompt 1
P2: Using the prolog-dev skill, write split_list(List, Left, Right) that splits a list into two non-empty parts, keeping order, for every possible split point.

## Prompt 2
P2: Write expr(Numbers, Tree, Value) that generates every expression tree over the numbers in order (a single number, or two sub-expressions joined by +, -, *, /), computing its integer value, where division is allowed only when exact and the divisor is non-zero.

## Prompt 3
P2: Write expr_string(Tree, String) that prints an expression tree in the canonical form: no spaces, * and / bind tighter than + and -, left operand in parentheses only if its operator has lower precedence than the parent, right operand in parentheses if its operator has the same or lower precedence, and a single number never in parentheses.

## Prompt 4
P2: Write generate_equation(List, Equation) that gives one valid equation string L=R (left expression over a non-empty prefix, right over the rest, equal integer values), and fails without looping or errors when none exists, including for lists of length 0 or 1.

## Prompt 5
P2: Write all_equations(List, Equations) that collects every valid equation string for List, without duplicates, sorted with sort/2, giving [] when there are none.

## Prompt 6
P2: Write count_equations(List, N) that gives the length of the list returned by all_equations/2.
