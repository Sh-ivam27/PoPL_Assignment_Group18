## Prompt 1
S2: Using the scheme-dev skill, write my-length that returns the number of top-level elements of a list, as a tail-recursive named-let loop, since the built-in length is forbidden.

## Prompt 2
S2: Write my-map (function, list) using only the allowed built-ins, with a tail-recursive accumulator loop and a small my-reverse helper, since map and reverse are forbidden.

## Prompt 3
S2: Using my-length and my-map, write insert-if-short (x lst n) that inserts x at the front of every list, at every level of nesting, whose original length is less than n; the empty list is a list of length 0 and atoms are left unchanged.

## Prompt 4
S2: Write print-insert-result, which takes no arguments, reads x, lst and n in that order from standard input with read, and prints the result of insert-if-short with display followed by a newline, with no prompt or other text.
