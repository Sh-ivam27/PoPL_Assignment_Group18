## Prompt 1
S1: Using the scheme-dev skill, write the tree accessors tree-val, tree-left and tree-right for a binary tree represented as (value left right), where the empty tree is '().

## Prompt 2
S1: Write inorder-collect (tree, accumulator) that returns the values in left, node, right order without using append, and print-inorder that displays that list on one line followed by a newline.

## Prompt 3
S1: Write preorder-collect and postorder-collect in the same accumulator style as inorder-collect, and print-all-traversals that displays the inorder, preorder and postorder lists on three lines, each followed by a newline.

## Prompt 4
S1: Write tree-metrics that returns the height and the leaf count of a tree in a single pass (the empty tree is (0 . 0), a single node is (1 . 1)), and print-height-and-leaves that displays the list (height leaf-count) on one line followed by a newline.

## Prompt 5
S1: Write tests/test_q3.rkt, a test file with no #lang line so it can be appended to code/18_q3.rkt, covering the PDF examples (t1, t2, t3 and the empty tree) plus a single node, left-only and right-only chains, a mixed tree and a depth-10000 tree, for all three printing functions.
